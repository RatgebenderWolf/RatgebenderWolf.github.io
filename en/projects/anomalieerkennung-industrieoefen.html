Master's programme — project 1

Feasibility study on ML-based anomaly detection for industrial furnaces

Completed 09.2025 — 02.2026

About

This master class project examined the feasibility of machine-learning-based anomaly detection for industrial pusher-type furnaces. The goal was to develop an analysis system that automatically detects unusual deviations in furnace operation from historical process data and makes them usable for service, commissioning and analysis purposes.

The data basis was real process data from a pusher-type furnace, including temperature setpoints and actual values as well as controller outputs for various furnace zones. After extensive data preparation and segmentation of furnace operation into individual cycles and process phases, a machine learning model was developed to detect deviations from normal operation.

As no labelled fault data was available, a one-class approach was used: it learns typical operating behaviour and rates irregularities via an anomaly score. The results are presented both as text and graphically, to support technical users in analysing critical operating states.

The work is designed as a feasibility study for offline analysis of historical data. The architecture developed is modular and can later be extended with features such as a graphical user interface, online analysis or more comprehensive reporting.

My tasks

  • Planning and running tests to evaluate the model
  • Assessing the results
  • Documentation and visualisation of results

Conclusion

The results show that machine-learning-based anomaly detection for industrial pusher-type furnaces is fundamentally feasible and holds considerable potential for industrial use.
