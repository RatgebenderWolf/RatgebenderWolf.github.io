Bachelor study project 3

Automation of high-pressure cleaning of element frames: position detection and HMI

Completed 09.2024 — 02.2025

About

The main goal of the project is to produce a training video. Knowledge transfer in video format is to be applied in order to present the results worked out in the project. Broadly, the project is about automating the high-pressure cleaning of formwork elements; specifically, it deals with detecting the position of formwork elements inside the washing box.

Project objectives

  • Identifying and assessing methods for position detection
  • Defining requirements for a human-machine interface (HMI)
  • Producing a training video to disseminate the content developed

Research questions

  • How can the position of a stack of elements within the working area be determined?
  • What could an interface for this system look like?
